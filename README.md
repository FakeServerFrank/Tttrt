# Carrusel Optimizer

App Android (Kotlin + Jetpack Compose) con:
- Animación de entrada: robot que se ensambla, inyecta el teléfono y carga de 1 a 100.
- Botón "Disporcionar" -> explosión -> letras 3D "On carrusel" -> botón ABRIR.
- Pestaña "Optimización": optimiza el teléfono para juegos usando Shizuku.

## Compilar
- GitHub: sube el repo. En la pestaña Actions se compila solo y deja el APK en Artifacts.
- Android Studio: File > Open sobre esta carpeta y Run (JDK 17).

## Usar
1. Instala Shizuku y arráncalo (depuración inalámbrica o ADB).
2. Abre la app, entra en Optimización, toca "Conceder permiso" y luego "Optimizar para juegos".
